Candongueiro Simulator
Um jogo 2D feito em Godot onde conduzes um candongueiro pelas ruas de Luanda.
O projeto ainda está no início. Por agora só a primeira rua está pronta.
O que já funciona
Cenário em pixel art inspirado na Baía de Luanda
O carro anda para a frente e para trás
O carro muda entre duas faixas

Controlos
Seta direita: andar para a frente
Seta esquerda: andar para trás
Seta cima: faixa de cima
Seta baixo: faixa de baixo

O que vem a seguir
Câmara a seguir o carro
Uma segunda rua com uma curva
Passageiros, dinheiro e combustível
Como abrir o projeto
Instala o Godot 4.3 ou mais recente.
Descarrega ou clona este repositório.
No Godot, escolhe Importar e abre o ficheiro project.godot.
Carrega em F5 para jogar.
