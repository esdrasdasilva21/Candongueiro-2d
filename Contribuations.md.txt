Contribuindo com o Projeto Candongueiro 🚐🇦🇴

Obrigado por ajudar a melhorar a mobilidade urbana na banda! Toda contribuição — seja código, design, sugestões ou atualização de rotas — é muito bem-vinda.

🤝 Regras Básicas

Mantenha o respeito e a empatia com todos os colaboradores. Queremos uma comunidade aberta e construtiva.

🚀 Como Ajudar

Bugs e Ideias: Abra uma Issue descrevendo o problema ou a sugestão (ex: novas rotas, tarifas, melhorias de UI).

Dados e Rotas: Ajude a manter as paragens, praças e itinerários atualizados.

Código: Resolva Issues abertas ou implemente melhorias.

🛠️ Fluxo de Trabalho (Passo a Passo)

Faça um Fork e clone o repositório:

git clone https://github.com/SEU-USUARIO/nome-do-repositorio.git
cd nome-do-repositorio


Instale as dependências e crie uma branch para a sua tarefa:

npm install # ou o gerenciador do seu projeto
git checkout -b feat/nome-da-tarefa


Faça commits claros seguindo o padrão Conventional Commits:

feat: nova funcionalidade (ex: feat: adiciona rota Viana - Congolenses)

fix: correção de bug (ex: fix: ajusta cálculo de tarifa)

docs: documentação

Envie (Push) e abra um Pull Request (PR):

git push origin feat/nome-da-tarefa


No GitHub, abra o Pull Request explicando brevemente o que foi feito (adicione prints se houver mudança visual).

Dúvidas? Abra uma Issue com a tag question. Tamo junto! 🇦🇴✨
